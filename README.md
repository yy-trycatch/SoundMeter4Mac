# AudioCatcher（声音分贝记录仪）

macOS 原生应用：用麦克风实时测量环境声级（A / C / Z 计权），并可在噪音达标时自动用摄像头录制带水印的视频作为留证。

## 功能

- **实时分贝测量**：每秒输出一条 Leq(1s) 记录，同时给出 dB(A)、dB(C)、dB(Z)，按 IEC 61672-1 在频域做计权。这三项读数不做任何降噪，保持原始测量值。
- **撞击声通道（邻里噪音）**：针对楼上蹦跳、敲击墙体，单独做一路 20–250 Hz 带通（4 阶 Butterworth）+ Fast(125 ms) 时间计权，取每秒最大值，并扣除自动估计的背景噪声底。人声、电视等中高频声音被带通滤掉；冰箱、空调等持续低频声被背景噪声底扣掉。背景噪声底取每秒最安静的 125 ms，变安静时立即下调，变吵时每秒最多上调 0.5 dB，所以持续的蹦跳不会被当成背景。
- **曲线与统计**：可切换 1 分钟 / 2 分钟 / 10 分钟 / 全部窗口；统计面板显示当前值、Leq、最小、最大。
- **CSV 导出**：UTF-8 带 BOM，Excel 可直接打开；列为 时间、dB(A)、dB(C)、dB(Z)、撞击声(扣背景)、撞击频段背景、高于背景 dB、校准偏移。
- **摄像头录制**：H.264 + AAC 的 mp4，默认保存到 `~/Downloads`，可更改目录。
- **两种采集模式**
  - 手动：点「开始」立即录制。
  - 自动：点「开始」只做音频监听，摄像头待命；撞击频段的 Fast 最大值高出背景达到判据（默认 10 dB）才开启摄像头并录一段，录满设定时长后自动保存并关闭摄像头，回到监听，下次检测到撞击再录。
- **视频水印**（预览与录制文件一致），按顺序显示：时间、位置、经纬度、权重（C 或 A）、最大分贝、最小分贝、当前分贝、撞击声（扣背景后的声级及高于背景的 dB 数）、当前录制时长。

## 系统要求

- macOS 13.0 及以上
- 已安装 Xcode 命令行工具（提供 `swiftc`、`codesign`、`iconutil`）

## 构建与运行

不需要 Xcode 工程，直接用脚本组装 app bundle：

```bash
./build.sh
open build/AudioCatcher.app
```

`build.sh` 会用 `swiftc` 编译 `Sources/*.swift`，目标架构跟随本机（`uname -m`），并做 ad-hoc 代码签名（麦克风权限依赖稳定的签名标识）。

## 权限

首次使用会请求以下权限，需要允许：

- 麦克风：测量声级、录制视频音轨
- 摄像头：录制视频
- 定位：水印中的位置与经纬度（地址解析需要联网，经纬度不需要）

被拒绝后可在「系统设置 → 隐私与安全性」中重新开启。定位被拒绝时水印显示「定位权限被拒绝」。

## 使用说明

1. 选择模式（手动 / 自动）。自动模式可设置：
   - 撞击判据：20–250 Hz 的 Fast 最大值高出背景多少 dB 算一次撞击，范围 3–40，默认 10。误触发多就调高，漏掉轻的脚步声就调低
   - 单段时长：0.5–30 分钟，默认 3 分钟
   - 连续撞击：连续多少秒都检测到撞击才触发，默认 1 秒（单次撞击即触发）
2. 选择「水印权重」C 或 A，仅影响水印显示，不影响触发判据（触发固定按撞击声通道）。
3. 点「开始」（或空格键）。自动模式下未检测到撞击时，视频窗口中间会显示当前判据。
4. 需要时点「导出 CSV」保存记录，「清空记录」会同时重置水印中的最大 / 最小值。

Mac 内置麦克风在 100 Hz 以下灵敏度会下降，楼板低频撞击读数会偏低。要采集更清楚，建议外接频响能到 20 Hz 的 USB 测量麦克风，并放在靠近天花板或墙面的位置。

### 校准

麦克风读数为 `dB SPL = dBFS + 校准偏移`，默认偏移 94 dB。要得到可信的绝对值，请用已知声级的参考声源（如声级校准器）调整「校准偏移」。未校准时的读数只适合做相对比较。

## 水印说明

- 最大 / 最小分贝为本次会话累计值（自上次「清空记录」起），与界面统计面板一致。
- 位置通过反向地理编码得到，移动超过 100 米才会重新解析。

## 项目结构

```
build.sh                  构建脚本
Sources/
  App.swift               入口与主界面
  AudioMeter.swift        麦克风采集、FFT 计权、统计
  Weighting.swift         A / C / Z 计权曲线
  ImpactDetector.swift    撞击声通道：带通、Fast 计权、背景噪声底扣除
  CameraRecorder.swift    摄像头、自动触发、水印、录制
  CameraSection.swift     摄像头区域界面
  LocationProvider.swift  定位与反向地理编码
  Exporter.swift          CSV 导出
  Info.plist              应用信息与权限说明
  AppIcon.icns            应用图标
tools/GenIcon.swift       图标生成工具
```
